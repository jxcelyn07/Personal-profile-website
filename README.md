# 🌐 My Profile Webpage

A simple and responsive personal profile webpage built using **HTML** and **CSS**. This project showcases my profile, hobbies, fun facts, skills, and contact information in a clean and visually appealing layout.

## ✨ Features

- Responsive navigation bar
- Professional profile section
- About Me section
- Hobbies and Fun Facts cards
- Skills section with ratings
- Contact information with GitHub, Email, and Phone
- Custom-designed background images
- Personalized favicon
- Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Google Fonts

## 🎯 Learning Outcomes

This project helped me learn:

- HTML page structure
- CSS styling and layouts
- CSS Grid
- Navigation using anchor links
- Working with images and icons
- Creating responsive sections
- Organizing project files
- Publishing projects on GitHub
